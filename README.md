# Luon

This is the official community and issue tracker for
[https://luon.dev](https://www.luon.dev), a lightweight full-stack platform for building
and running Sites with View and CLI.

Use this repository to report problems, request features, improve
documentation, or ask for development help across the complete Luon product
family.

## Open an issue

[Create a Luon issue](https://github.com/predeve/luon/issues/new/choose)

The tracker accepts reports for:

- View, UI, Act, Rule, and Style
- CLI, Agent, and WebView
- Runtime, Worker, and Provider
- Core, Hub, and Gateway
- Package, CDN, Templates, websites, and documentation

Choose the closest product in the issue form. If a problem crosses several
products, choose `Multiple products` and describe the complete flow.

## Before posting

- Search existing issues first.
- Confirm the problem with the latest available release when possible.
- Include the operating system, CPU architecture, Bun version, and Luon
  versions.
- Add a small reproduction or the exact command that failed.
- Remove tokens, credentials, private URLs, customer data, and other secrets.

Public development help is provided on a best-effort basis. An Issue is not a
private support channel or an uptime guarantee.

## Security

Do not disclose a vulnerability in a public Issue. Use
[private vulnerability reporting](https://github.com/predeve/luon/security/advisories/new)
so the report and any sensitive details remain private until a fix is ready.
